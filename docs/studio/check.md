# Check

ビルドの前に解決が必要な項目を確認するタブです。

## 解決が必要な項目がある場合

![解決が必要な項目](/img/studio/check-items.png)

項目の件数と、それぞれの内容が表示されます。ボタンが付いた項目は、ボタンを押すと解決します。

ほかのタブを開いているときも、タブの下に件数と「Check を開く」が表示されます。

![ほかのタブに表示される件数](/img/studio/check-band.png)

項目ごとの直し方は [トラブルシューティング](../help/troubleshooting.md) を参照してください。

## 解決が必要な項目が無い場合

「問題はありません。」と表示されます。

![解決が必要な項目が無い Check タブ](/img/quick-start/check.png)

動画の外部 URL は Unity の Play モードでは再生できないため、音はビルドして VRChat で確認します。手順は [クイックスタート](../getting-started/quick-start.md#ビルドして-vrchat-で確認する) を参照してください。
