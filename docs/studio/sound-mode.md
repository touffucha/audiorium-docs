# Sound Mode

コンソールの Sound Mode タブに表示する、音のプリセットを編集するタブです。ユーザーはコンソールでプリセットを切り替えます。変更は Scene にすぐに適用されます。

![Sound Mode タブ](/img/studio/sound-top.png)

## プリセット

![プリセットのカードと、EQ・REVERB のグラフ](/img/studio/sound-presets.png)

デフォルトで 5 種類のプリセットがあります。カードを押すと、右側でそのプリセットを編集できます。

| プリセット | 説明文（デフォルト） |
| --- | --- |
| Cinema | 映画の迫力、豊かな低音 |
| Concert | 豊かな残響、空間に広がる音 |
| Lounge | 柔らかな音、部屋の自然な響き |
| Submerged | 水中のような響き、広がる低音 |
| Radio | レトロな音色、残響のない音 |

カードの下段は、左が Low Cut の周波数（Full は Low Cut なし）、右が Reverb の種類です。左下の EQ と REVERB のグラフで、選択したプリセットの特性を確認できます。

![選択したプリセットの名前と説明文](/img/studio/sound-editor.png)

| 項目 | 内容 |
| --- | --- |
| デフォルトプリセット | 入室時に適用するプリセットに設定します |
| 名前 | コンソールのプリセットのカードに表示されます。半角英数字と記号のみ使用できます |
| 説明文 | 最大 2 行。カードの名前の下に表示されます |
| リセット | このプリセットをデフォルトに戻します。名前・説明文・スピーカーごとの値もリセットされます。変更したプリセットにのみ表示されます |

## EQ

![EQ タブ](/img/studio/sound-eq.png)

| 項目 | 内容 |
| --- | --- |
| LOW CUT | この周波数より低い音をカットします |
| HIGH CUT | この周波数より高い音をカットします |
| Q | カットオフ周波数付近の強調の度合いです。1.0 では強調しません。1.0 より大きくすると、カットオフ周波数付近の帯域が大きく聞こえます |

## 音量

![音量タブ](/img/studio/sound-level.png)

| 項目 | 内容 |
| --- | --- |
| VOLUME | 音量です。0 % で無音になります |
| REVERB SEND | 音を Reverb へ送る量です。大きいほど残響が増えます |

## スピーカーごとに調整する

EQ と音量の値は、スピーカーごとに変えられます。「スピーカーごとに調整」をオンにすると、スピーカーのチップが表示されます。チップを押すと、そのスピーカーの値だけを変更します。

![「スピーカーごとに調整」をオンにして Sub を選択した状態](/img/studio/sound-per-speaker.png)

- ● が付いたスピーカーは、ほかのスピーカーと違う値を持っています。オフのときは、違う値のスピーカーがあると「スピーカーごとに調整」の横に ● が表示されます。
- オフのときに変更した値は、● の無いスピーカーに適用されます。
- ● が付いたスピーカーを選択すると、「ほかのスピーカーと同じ値に戻す」が表示されます。押すと、そのスピーカーの EQ と音量がほかのスピーカーと同じになります。

デフォルトのプリセットは、スピーカーの役割に合わせて値を変えています。たとえば Sub は低音域だけを鳴らす値を持つため、最初から ● が付いています。

## Reverb

![Reverb タブ](/img/studio/sound-reverb.png)

Reverb は全スピーカー共通です。種類を Room、Hall、Cathedral、Off から選択し、値を調整します。

| 項目 | 内容 |
| --- | --- |
| Room | 小さな部屋のような短い残響 |
| Hall | ホールのような中程度の残響 |
| Cathedral | 大聖堂のような長い残響 |
| Off | 残響なし |
| WET | 残響音の音量です。0 % で残響がなくなります |
| REVERB LEVEL | 原音に対する残響の量です。上げると全体の音量も上がります |
| DECAY | 残響が消えるまでの時間です |
| HF DECAY | 高域の残響が消えるまでの時間です。短くすると残響が暗くなります |
| PRE-DELAY | 残響が始まるまでの時間です |
