# Sound Mode

コンソールの Sound Mode タブに表示する、音のプリセットを編集するタブです。ユーザーはコンソールでプリセットを切り替えます。

![Sound Mode タブ](/img/studio/sound-top.png)

## プリセット

![プリセットのカード](/img/studio/sound-presets.png)

デフォルトで 5 種類のプリセットがあります。カードを押すと、右側でそのプリセットを編集できます。

| プリセット | 説明文（デフォルト） |
| --- | --- |
| Cinema | 映画の迫力、豊かな低音 |
| Concert | 豊かな残響、空間に広がる音 |
| Lounge | 柔らかな音、部屋の自然な響き |
| Submerged | 水中のような響き、広がる低音 |
| Radio | レトロな音色、残響のない音 |

カードの下段は、左が Low Cut の周波数（Full は Low Cut なし）、右が Reverb の種類です。左下の EQ と REVERB のグラフで、選択したプリセットの特性を確認できます。

| 項目 | 内容 |
| --- | --- |
| デフォルトプリセット | 入室時に適用するプリセットに設定します |
| 名前 | コンソールのプリセットのカードに表示されます。半角英数字と記号のみ使用できます |
| 説明文 | 最大 2 行。カードの名前の下に表示されます |
| リセット | このプリセットをデフォルトに戻します。名前・説明文・スピーカーごとの値もリセットされます |

## EQ / 音量

![選択したプリセットの編集](/img/studio/sound-editor.png)

値を設定する対象を、「全体」か、スピーカーのチップから選択します。

| 対象 | 適用される範囲 |
| --- | --- |
| 全体 | 個別の値を持たないスピーカーすべて |
| スピーカー（Front・Surround・Room・Sub など） | そのスピーカーのみ。全体の値より優先されます |

スピーカーの値を全体の値に戻すときは、「上書きを解除」を押します。

![EQ と音量の設定](/img/studio/sound-eq.png)

| 項目 | 内容 |
| --- | --- |
| LOW CUT | この周波数より低い音をカットします |
| HIGH CUT | この周波数より高い音をカットします |
| Q | カットオフ周波数付近の強調の度合いです。1.0 では強調しません。1.0 より大きくすると、カットオフ周波数付近の帯域が大きく聞こえます |
| VOLUME | 対象の音量です。0 % で無音になります |
| REVERB SEND | 対象の音を Reverb へ送る量です。大きいほど残響が増えます |

## Reverb

Reverb は全スピーカー共通です。種類を Room、Hall、Cathedral、Off から選択し、値を調整します。

| 項目 | 内容 |
| --- | --- |
| Room | 小さな部屋のような短い残響 |
| Hall | ホールのような中程度の残響 |
| Cathedral | 大聖堂のような長い残響 |
| Off | 残響なし |
| Wet | 残響音の音量です。0 % で残響がなくなります |
| Reverb Level | 原音に対する残響の量です。上げると全体の音量も上がります |
| Decay | 残響が消えるまでの時間です |
| HF Decay | 高域の残響が消えるまでの時間です。短くすると残響が暗くなります |
| Pre-Delay | 残響が始まるまでの時間です |
