# Console

ワールドに配置するコンソールの見た目と、操作の設定を行うタブです。

![Console タブ](/img/studio/console-top.png)

## コンソール

配置しているコンソールの名前が表示されます。「Hierarchy で選択」を押すと、コンソールを Hierarchy で選択します。コンソールの位置と向きは、Scene ビューで調整します。

## 設置モデル

![コンソールと設置モデル](/img/studio/console-mount.png)

コンソールを置く台の形を選択します。

| 置き場所 | 設置モデル |
| --- | --- |
| 床 | 折り板スタンド、両袖デスク |
| 壁 | 壁面フラット、壁面プレート、壁面チルト、壁面デスク、棚板とブラケット |
| 卓上 | 卓上ドック、卓上折り板 |
| 手元 | Pickup、Pickup とドック |
| 空中 | 枠のみ |

「仕上げ」で、台の色を白、チャコール、黒御影石、木から選択します。「Pickup とドック」では、Pickup をドックに戻したときの「ドック装着音」を設定できます。

壁の設置モデルは、コンソールの後ろに壁がある位置に配置します。壁が見つからない場合はメッセージが表示されます。

## テーマ

![テーマと最初に開くタブ](/img/studio/console-theme.png)

コンソールの画面の配色を、16 種類から選択します。

## 最初に開くタブ

入室時にコンソールが最初に表示するタブです。Scene のコンソールにも表示されます。

## ワールド全体の設定の操作権限

![操作権限の選択肢](/img/studio/console-access.png)

Sound Mode・Speaker EQ・Live を変更できる人を、全員、インスタンスオーナー、登録したユーザーから選択します。詳しくは [操作権限](../console/permissions.md) を参照してください。

## 操作音

![操作音](/img/studio/console-sounds.png)

コンソールの操作時に再生される効果音です。

| 場面 | 内容 |
| --- | --- |
| 押下・オン | ボタンを押したとき、スイッチをオンにしたとき |
| オフ | スイッチをオフにしたとき |
| スライダー操作 | スライダーを動かしている間 |
| スライダー解放 | スライダーから手を離したとき |
| 操作権限なし | 操作権限の無い人が操作したとき |

AudioClip を欄へドラッグするか、◎ を押して選択します。▶ で試聴し、右端のボタンでデフォルトの音にリセットします。VOLUME で、操作音全体の音量を調整します。

## 外部ギミックとの連携

![外部ギミックとの連携](/img/studio/console-external.png)

ほかのギミックの Udon から、コンソールの操作権限を許可・禁止するためのイベントです。詳しくは [操作権限](../console/permissions.md#外部ギミックとの連携) を参照してください。
