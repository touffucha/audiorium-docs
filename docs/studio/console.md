# Console

ワールドに配置するコンソールの見た目と、操作の設定を行うタブです。

![Console タブ](/img/studio/console-top.png)

## コンソール

配置しているコンソールが表示されます。押すと、Hierarchy でコンソールを選択します。

コンソールは、視聴位置からスクリーンの方へ 0.9 m の位置に配置されます。位置と向きは、Scene ビューで調整します。

## 設置モデル

![設置モデルと仕上げ。床の「床置き」を選択した状態](/img/studio/console-mount.png)

コンソールを置く台を選択します。上の置き場所（床、壁、卓上、手元、空中）を押すと、その置き場所の設置モデルが表示されます。カードを押すと、Scene のコンソールの台が替わります。今の台の置き場所には「設置中」と表示されます。

![設置モデルの一覧](/img/studio/console-mounts.png)

| 置き場所 | 設置モデル | 内容 |
| --- | --- | --- |
| 床 | 床置き | 床に立てるスタンド。デフォルトです |
| 壁 | 壁掛け | 壁に掛ける台。コンソールの後ろに壁がある位置で使います |
| 卓上 | 卓上 | 机やカウンターに置く台 |
| 手元 | 手持ち | 手に持って操作するコンソール |
| 手元 | 置き台 | 手持ちのコンソールと、それを戻す置き台 |
| 空中 | 枠のみ | 台を付けず、コンソールの画面と枠だけを置きます |

![手元の「手持ち」と「置き台」](/img/studio/console-mount-handheld.png)

「仕上げ」で、台の色をホワイトかチャコールから選択します。枠のみでは選択できません。

「置き台」では、手持ちのコンソールを置き台に戻したときに鳴る「ドック装着音」を設定できます。

壁掛けを選択したときにコンソールの後ろに壁が見つからない場合は、メッセージが表示されます。コンソールを壁の位置へ移動してから、選択し直します。

## テーマ

![テーマの一覧](/img/studio/console-theme.png)

コンソールの画面の配色を、16 種類から選択します。各テーマの画像は、そのテーマで表示したコンソールです。

## 最初に開くタブ

![最初に開くタブ](/img/studio/console-start-page.png)

入室時にコンソールが最初に表示するタブです。デフォルトは Sound Mode です。Scene のコンソールにも、このタブが表示されます。

## 操作権限

![操作権限の選択肢](/img/studio/console-access.png)

コンソールの Sound Mode・Speaker EQ・Live のタブを操作できる人を、全員、インスタンスオーナー、登録したユーザーから選択します。Effects は操作権限の対象外です。詳しくは [操作権限](../console/permissions.md) を参照してください。

## UI 操作音

![UI 操作音](/img/studio/console-sounds.png)

コンソールの操作時に再生される効果音です。

| 場面 | 内容 |
| --- | --- |
| 押下・オン | ボタンを押したとき、スイッチをオンにしたとき |
| オフ | スイッチをオフにしたとき |
| スライダー操作 | スライダーを動かしている間 |
| スライダー解放 | スライダーから手を離したとき |
| 操作権限なし | 操作権限の無い人が操作したとき |

AudioClip を欄へドラッグするか、◎ を押して選択します。▶ で試聴し、右端のボタンでデフォルトの音にリセットします。VOLUME で、操作音全体の音量を調整します。
