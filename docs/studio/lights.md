# Lights

照明システム（拡張パッケージ）の照明のセットを配置するタブです。照明システムをインポートすると使用できます。

![Lights タブ。左の図で位置と向きを決める](/img/studio/lights-top.png)

## 照明のセットを配置する

![照明のセットの一覧](/img/studio/lights-sets.png)

1. 右側の「照明のセット」から、セットを選択します。
2. 左の図で、ドラッグしてセットを移動します。上からの図では小さな円のドラッグで向き、前・横の図では上下のドラッグで高さを変更します。
3. 「反映」を押します。

必要な数だけ配置できます。配置したセットは「配置したセット」に表示され、「このセットを削除」で削除できます。

| 区分 | セット | 内容 |
| --- | --- | --- |
| ライト単体 | 吊り 2 灯 | ムービングライト 2 台。天井や梁に取り付けます。小さな部屋に適しています |
| ライト単体 | 吊り 4 灯 | ムービングライト 4 台。幅 4 m 程度より広いスクリーンに適しています |
| ライト単体 | 床置き | ムービングライト 2 台。床に置いて上方を照らします。天井の低い部屋に適しています |
| ライト単体 | ストロボ | ストロボ 2 台。コンソールの Strobe で発光します |
| ライト単体 | LED バー | LED バー 2 本。コンソールの Wash と曲に連動して発光します |
| トラス付き | 2 m、4 m、床置き、ストロボ、LED バー | トラス（照明を吊る金属の枠）ごと表示します。トラスの支柱は含まれないため、天井の近くに配置します |
| スタンド付き | スタンド | 三脚スタンド 2.2 m、ムービングライト 2 台。客席やスクリーンの脇に適しています |

ライトショーで制御できるムービングライトは 16 台までです。台数は「ムービングライト 4 / 16」のように表示されます。

![配置した照明のセット（M1）が図に表示される](/img/studio/lights-plan.png)

照明は、コンソールの Live タブでルックを選択すると点灯します。Scene に AudioLink がある場合は、音にも連動します。

## 入場時の光過敏の警告

照明やストロボの点滅に対する注意を、入場した人に表示する看板です。「入場時に表示」をオンにすると配置されます。この設定は「反映」を待たずに Scene に適用されます。

| 項目 | 内容 |
| --- | --- |
| 左右・奥行き・床からの高さ・向き | 看板の位置と向き |
| 同意するまで通行できない範囲 | 幅と高さ。ユーザーは「I UNDERSTAND」を押すまで、この範囲を通れません |
| Scene ビューで表示 | 看板を Scene ビューに表示します |
| 言語 | 看板の言語。「コンソールと同じ」を選択できます |
| 見出し・本文・ボタン | 看板に表示する文 |
