# Speakers

動画プレイヤーの接続と、スピーカーのレイアウトを選択するタブです。スピーカーの位置は Scene ビューで、スピーカーごとの設定は Inspector で変更します。

![Speakers タブ](/img/studio/speakers.png)

## 動画プレイヤーとスクリーン

![動画プレイヤーとスクリーン](/img/studio/speakers-player.png)

| 項目 | 内容 |
| --- | --- |
| 動画プレイヤー | 接続している動画プレイヤー。別の動画プレイヤーを指定すると、接続先が替わります |
| スクリーン | 動画を映すスクリーンの MeshRenderer。スピーカーとコンソールの位置の基準になります |

## レイアウト

![レイアウトのカードと、Room・Sub の使用](/img/studio/speakers-layout.png)

スピーカーの構成を選択します。選択した後に「反映」を押すと、スピーカーが配置され、視聴位置で基準レベルになるように各スピーカーの音量が揃えられます。

| レイアウト | 出力数 | 構成 |
| --- | --- | --- |
| Stereo | 4 | 前方の左右（FL・FR）、Room、Sub |
| Surround | 6 | Stereo に、後方の左右（SL・SR）を追加 |
| Surround + Top | 8 | Surround に、上方の左右（TML・TMR）を追加 |

レイアウトを変更してスピーカーが減る場合は、確認のダイアログが表示されます。

| 項目 | 内容 |
| --- | --- |
| Room を使用 | 残響を鳴らす出力です。オフにすると、Reverb がほとんど効かなくなります |
| Sub を使用 | 動画の音声の低音域を鳴らす出力です |

## スピーカー一覧

![スピーカー一覧](/img/studio/speakers-units.png)

配置しているスピーカーの一覧です。スピーカーを押すと、Hierarchy でそのスピーカーを選択します。Shift を押しながら押すと選択に追加、ダブルクリックで Scene ビューに表示します。

「Scene ビューに可聴範囲を表示」をオンにすると、Scene ビューに各スピーカーの音が聞こえる範囲を表示します。

## スピーカーの配置

![スピーカーの配置の図](/img/studio/speakers-plan.png)

上・前・横から見た図で、スピーカー、コンソール、スクリーン、視聴位置の位置関係を確認します。スピーカーの移動は Scene ビューで行います。図のスピーカーをダブルクリックすると、Scene ビューにそのスピーカーを表示します。

## 視聴位置での音量バランス

![視聴位置での音量バランス](/img/studio/speakers-balance.png)

視聴位置で聞こえる各スピーカーの音量を表示します。0 が、一般的な音量の動画を再生したときの基準レベルで、枠内が適正レベルです。設定値から算出した推定値で、実測値ではありません。

- 右側に、全体のレベルと、スピーカーどうしの差（「バランス均一」または「最大 n dB の差」）が表示されます。
- 各スピーカーのバーをドラッグすると、トリムを変更できます。
- 遠いスピーカーの音量が足りない場合は、そのスピーカーを視聴位置に近づけます。

## 音声バッファ

![音声バッファ](/img/studio/speakers-buffer.png)

動画の音声をスピーカーへ送る前に保持する量（サンプル数）です。2048、4096、8192 から選択します。デフォルトは 4096 です。小さいほど遅延が短くなります。表示される遅延は、表示されたサンプルレートでの値で、機器の遅延は含みません。

## Inspector で変更する項目

スピーカーの追加と、スピーカーごとの設定は、Inspector で行います。

### スピーカーを追加する

![AudioriumSetup の Inspector。「L / R ペアを追加」と「単体スピーカーを追加」](/img/studio/speakers-inspector-setup.png)

Hierarchy で `AudioriumSetup` を選択し、Inspector の「L / R ペアを追加」か「単体スピーカーを追加」を押します。スピーカーは動画プレイヤーの位置に追加されます。位置は Scene ビューで調整します。出力は、Room と Sub を含めて 8 つまで使用できます。

スピーカーの名前は、Hierarchy で GameObject の名前を変更すると変わります。

### スピーカーごとの設定

![スピーカーの Inspector](/img/studio/speakers-inspector-speaker.png)

Hierarchy でスピーカー（`Front` など）を選択すると、Inspector に設定が表示されます。

| 項目 | 内容 |
| --- | --- |
| 入力 | 動画プレイヤーのどの音源をつなぐか。動画プレイヤーの音源が 1 つの場合は変更できません |
| 種類 | L / R ペア、単体 · Stereo、単体 · L、単体 · R |
| 役割 | Front・Surround・Ceiling など。視聴位置から見たスピーカーの位置で自動的に決まります |
| 出力ごとの補正 | ワールドの音響に合わせて、出力ごとの音量を補正します。コンソールやプリセットの操作では変更されません |
| 音が届く範囲を設定 | 「2D で聴こえる範囲」と「音が消える距離」を指定し、「この範囲を適用」を押します。内側は 2D、外側へ進むと 3D へ移行しながら音量が下がり、指定した距離で無音になります |
