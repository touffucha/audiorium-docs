# Speakers

動画プレイヤーの接続と、スピーカーの構成を設定するタブです。

![Speakers タブ](/img/studio/speakers.png)

## 動画プレイヤーとスクリーン

![動画プレイヤーとスクリーン](/img/studio/speakers-player.png)

| 項目 | 内容 |
| --- | --- |
| 動画プレイヤー | 接続している動画プレイヤー。別の動画プレイヤーを指定すると、接続先が替わります |
| スクリーン | 動画を映すスクリーンの MeshRenderer。スピーカーとコンソールの位置の基準になります |

## レイアウト

![レイアウトのカード](/img/studio/speakers-layout.png)

スピーカーの構成を選択します。選択した後に「反映」を押すと、スピーカーが配置されます。

| レイアウト | 出力数 | 構成 |
| --- | --- | --- |
| Stereo | 4 | 前方の左右（FL・FR）、Room、Sub |
| Surround | 6 | Stereo に、後方の左右（SL・SR）を追加 |
| Surround + Top | 8 | Surround に、上方の左右（TML・TMR）を追加 |

レイアウトを変更してスピーカーが減る場合は、確認のダイアログが表示されます。

## スピーカーの配置

![スピーカーの配置の図](/img/studio/speakers-plan.png)

上・前・横から見た図で、スピーカー、コンソール、スクリーン、視聴位置の位置関係を確認します。スピーカーの移動は Scene ビューで行います。図のスピーカーを押すと選択、Shift を押しながら押すと選択に追加、ダブルクリックで Scene ビューに表示します。

## 視聴位置での音量バランス

![視聴位置での音量バランス](/img/studio/speakers-balance.png)

視聴位置で聞こえる各スピーカーの音量を表示します。0 が、一般的な音量の動画を再生したときの基準レベルで、枠内が適正レベルです。設定値から算出した推定値で、実測値ではありません。

- 「レベルを揃える」を押すと、各スピーカーの音量を基準レベルに合わせます。
- 各スピーカーのバーをドラッグすると、トリムを変更できます。
- 遠いスピーカーの音量が足りない場合は、そのスピーカーを視聴位置に近づけます。

## スピーカー一覧

![スピーカー一覧](/img/studio/speakers-units.png)

| 項目 | 内容 |
| --- | --- |
| Scene ビューに可聴範囲を表示 | Scene ビューに、各スピーカーの音が聞こえる範囲を表示します |
| Front・Surround・Top Middle など | 左右で 1 組の出力。押すと、そのスピーカーの設定を表示します |
| Room | 残響を鳴らす出力。動画プレイヤーの位置に配置されます。オフにすると、Reverb がほとんど効かなくなります |
| Sub | 低音を鳴らす出力。動画プレイヤーの位置に配置されます |
| L / R ペアを追加・単体スピーカーを追加 | スピーカーを追加します。出力は Room と Sub を含めて最大 8 です |

### スピーカーの設定

![選択したスピーカーの設定](/img/studio/speakers-unit-settings.png)

一覧のスピーカーを選択すると、そのスピーカーの設定が表示されます。

| 項目 | 内容 |
| --- | --- |
| 名前 | スピーカーの名前。半角英数字・空白・`_`・`-` を使用し、ほかと重複しない名前にします |
| 役割 | Front・Surround・Ceiling など。「役割を自動で割り当て」では、スピーカーの位置から決まります |
| 種類 | L / R ペアか、単体のスピーカーか |
| 固定先のオブジェクト | スピーカーを追従させる GameObject |
| 可聴範囲 | 「視聴位置に合わせて設定」か「距離で指定」。距離で指定する場合は、減衰開始距離までは音量を維持し、減衰終了距離で無音になります |

## 音声バッファ

![音声バッファ](/img/studio/speakers-buffer.png)

動画の音声をスピーカーへ送る前に保持する量（サンプル数）です。2048、4096、8192 から選択します。デフォルトは 4096 です。小さいほど遅延が短くなります。表示される遅延は、表示されたサンプルレートでの値で、機器の遅延は含みません。
