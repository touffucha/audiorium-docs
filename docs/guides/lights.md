# 照明を配置する

照明システム（拡張パッケージ）のセットを配置します。照明システムをインポートすると、Studio の Lights タブが使用できます。

## 照明のセットを配置する

1. Studio の Lights タブを開きます。
2. 「照明のセット」から、配置するセットを選択します。

   ![照明のセットの一覧](/img/studio/lights-sets.png)

3. 左の図で、位置・向き・高さを調整します。
   - 位置：セットをドラッグします。
   - 向き：上からの図で、小さな円をドラッグします。
   - 高さ：前・横の図で、上下にドラッグします。
4. 「反映」を押します。

![配置した照明のセット（M1）が図に表示される](/img/studio/lights-plan.png)

セットは複数配置できます。ライトショーで制御できるムービングライトは 16 台までです。

## 照明のセットを削除する

1. 「配置したセット」から、削除するセットを選択します。
2. 「このセットを削除」を押します。
3. 「反映」を押します。

## 点灯を確認する

1. ビルドして、VRChat でコンソールの Live タブを開きます。
2. ルックを選択し、照明が点灯することを確認します。Scene に AudioLink がある場合は、音にも連動します。

:::warning

照明とストロボには点滅が含まれます。[入場時の光過敏の警告](./entry-notice.md) の表示を検討してください。

:::

セットの種類は [Lights](../studio/lights.md) を参照してください。
