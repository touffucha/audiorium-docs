# Sound Mode のプリセットを編集する

コンソールの Sound Mode タブに表示する 5 つのプリセットを編集します。変更は Scene にすぐに適用されます。

## 名前と説明文を変更する

1. Studio の Sound Mode タブを開き、編集するプリセットのカードを押します。
2. 右側の「名前」と「説明文」を変更します。名前は半角英数字と記号のみ使用できます。説明文は最大 2 行です。

![選択したプリセットの編集](/img/studio/sound-editor.png)

## デフォルトプリセットを指定する

1. 入室時に適用するプリセットのカードを押します。
2. 右上の「デフォルトプリセット」をオンにします。

## EQ と音量を調整する

1. 「EQ / 音量」を開きます。
2. 調整する対象を、「全体」か、スピーカーのチップから選択します。スピーカーを選択した場合は、そのスピーカーのみに適用されます。
3. LOW CUT、HIGH CUT、Q、VOLUME、REVERB SEND のスライダーを調整します。

![EQ と音量の設定](/img/studio/sound-eq.png)

スピーカーの値を全体の値に戻す場合は、「上書きを解除」を押します。

## Reverb を調整する

1. 「Reverb」を開きます。
2. 種類（Room、Hall、Cathedral、Off）を選択し、値を調整します。Reverb は全スピーカー共通です。

## プリセットをリセットする

1. プリセットのカードの「リセット」を押します。名前・説明文・スピーカーごとの値がデフォルトに戻ります。

各項目の詳細は [Sound Mode](../studio/sound-mode.md) を参照してください。
