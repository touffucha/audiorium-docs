# Sound Mode のプリセットを編集する

コンソールの Sound Mode タブに表示する 5 つのプリセットを編集します。変更は Scene にすぐに適用されます。

## 名前と説明文を変更する

1. Studio の Sound Mode タブを開き、編集するプリセットのカードを押します。
2. 右側の「名前」と「説明文」を変更します。名前は半角英数字と記号のみ使用できます。説明文は最大 2 行です。

![選択したプリセットの名前と説明文](/img/studio/sound-editor.png)

## デフォルトプリセットを指定する

1. 入室時に適用するプリセットのカードを押します。
2. 右上の「デフォルトプリセット」をオンにします。

## EQ と音量を調整する

1. 「EQ」タブで、LOW CUT、HIGH CUT、Q を調整します。
2. 「音量」タブで、VOLUME と REVERB SEND を調整します。

![EQ タブ](/img/studio/sound-eq.png)

値は、ほかと違う値を持たないスピーカーすべてに適用されます。

## スピーカーごとに調整する

1. 「EQ」か「音量」のタブで、「スピーカーごとに調整」をオンにします。
2. 調整するスピーカーのチップを押し、値を調整します。そのスピーカーのみに適用されます。

![「スピーカーごとに調整」をオンにして Sub を選択した状態](/img/studio/sound-per-speaker.png)

● が付いたスピーカーは、ほかと違う値を持っています。ほかのスピーカーと同じ値にするには、そのスピーカーを選択して「ほかのスピーカーと同じ値に戻す」を押します。

## Reverb を調整する

1. 「Reverb」タブを開きます。
2. 種類（Room、Hall、Cathedral、Off）を選択し、値を調整します。Reverb は全スピーカー共通です。

## プリセットをリセットする

1. 右上の「リセット」を押します。名前・説明文・スピーカーごとの値がデフォルトに戻ります。「リセット」は、変更したプリセットにのみ表示されます。

各項目の詳細は [Sound Mode](../studio/sound-mode.md) を参照してください。
