# スピーカーと視聴位置を調整する

レイアウトを反映した後に、部屋に合わせて視聴位置とスピーカーを移動します。

## 視聴位置を移動する

視聴位置は、ユーザーが動画を視聴する位置です。各スピーカーの音量は、レイアウトを反映したときに視聴位置を基準に揃えられます。

1. Hierarchy で `AudioriumSetup` の中にある `ListeningPosition` を選択します。
2. Scene ビューで、客席の中央に移動します。

![Hierarchy の ListeningPosition](/img/quick-start/listening-position.png)

## スピーカーを移動する

1. Studio の Speakers タブの「スピーカー一覧」で、スピーカーを押します。Hierarchy でそのスピーカーが選択されます。ダブルクリックすると、Scene ビューにそのスピーカーを表示します。
2. Scene ビューで移動します。

![スピーカー一覧](/img/studio/speakers-units.png)

特定のスピーカーの音量を変える場合は、Hierarchy でそのスピーカーを選択し、Inspector の「出力ごとの補正」で調整します。最終的な音量は、ビルドして VRChat で確認します。

:::warning

スピーカーや視聴位置を移動した後にレイアウトを選択し直すと、確認のダイアログが表示されます。「変更」を押すと、スピーカーと視聴位置が初期の配置に戻ります。

:::

## 動画プレイヤーを移動した場合

接続した後に動画プレイヤーを移動すると、Scene ビューの `AudioriumSetup` の位置に「画面に合わせる」が表示されます。押すと、スピーカー、コンソール、視聴位置が動画プレイヤーに合わせて移動します。床からの高さは、移動した先の床に合わせて保たれます。

各項目の詳細は [Speakers](../studio/speakers.md) を参照してください。
