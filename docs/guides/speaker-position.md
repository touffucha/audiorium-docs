# スピーカーと視聴位置を調整する

レイアウトを反映した後に、部屋に合わせて視聴位置とスピーカーを移動し、音量のバランスを調整します。

## 視聴位置を移動する

各スピーカーの音量は、視聴位置を基準に揃えられます。視聴位置を客席の中央に移動します。

1. Hierarchy で `AudioriumSetup` の中にある `ListeningPosition` を選択します。
2. Scene ビューで、客席の中央に移動します。

![Hierarchy の ListeningPosition](/img/quick-start/listening-position.png)

## スピーカーを移動する

1. Studio の Speakers タブで、「スピーカー一覧」か「スピーカーの配置」の図のスピーカーを押します。Hierarchy でそのスピーカーが選択されます。図のスピーカーをダブルクリックすると、Scene ビューにそのスピーカーを表示します。
2. Scene ビューで移動します。

![スピーカーの配置の図](/img/studio/speakers-plan.png)

## 音量のバランスを調整する

「視聴位置での音量バランス」で、各スピーカーが枠内（適正レベル）に収まっているかを確認します。0 が基準レベルです。

1. 音量が足りないスピーカーがある場合は、Scene ビューでそのスピーカーを視聴位置に近づけます。
2. 細かく合わせる場合は、各スピーカーのバーをドラッグしてトリムを変更します。

![視聴位置での音量バランス](/img/studio/speakers-balance.png)

:::note

表示される値は設定値から算出した推定値です。最終的な音量は、ビルドして VRChat で確認します。

:::

各項目の詳細は [Speakers](../studio/speakers.md) を参照してください。
