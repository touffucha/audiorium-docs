# コンソールの外観と位置を変更する

コンソールの台と色、位置、画面の配色、最初に開くタブを変更します。設定は Studio の Console タブで行います。

![Console タブ](/img/studio/console-top.png)

## 設置モデルと仕上げを変更する

1. 「設置モデル」で、置き場所（床、壁、卓上、手元、空中）を押します。
2. 設置モデルのカードを押します。Scene のコンソールの台がすぐに替わります。
3. 「仕上げ」で、台の色（ホワイト、チャコール）を選択します。

![設置モデルと仕上げ](/img/studio/console-mount.png)

| 置き場所 | 設置モデル |
| --- | --- |
| 床 | 床置き（デフォルト） |
| 壁 | 壁掛け |
| 卓上 | 卓上 |
| 手元 | 手持ち、置き台 |
| 空中 | 枠のみ |

壁掛けは、コンソールの後ろに壁がある位置で使用します。壁が見つからない場合はメッセージが表示されます。

## 位置と向きを変更する

コンソールは、視聴位置からスクリーンの方へ 0.9 m の位置に配置されます。

1. Console タブの「コンソール」の欄を押します。Hierarchy でコンソールが選択されます。
2. Scene ビューで、位置と向きを変更します。

## テーマを変更する

1. 「テーマ」で、画面の配色を 16 種類から選択します。各テーマの画像は、そのテーマで表示したコンソールです。
2. 右上の「反映」を押します。Scene のコンソールにテーマが適用されます。

## 最初に開くタブを変更する

1. 「最初に開くタブ」で、入室時にコンソールが表示するタブを選択します。デフォルトは Sound Mode です。

各項目の詳細は [Console](../studio/console.md) を参照してください。
