# 入場時の光過敏の警告を表示する

照明やストロボの点滅に対する警告の看板を、入場したユーザーに表示します。ユーザーは看板の「I UNDERSTAND」を押すまで、指定した範囲を通れません。照明システム（拡張パッケージ）が必要です。

:::note

この設定は「反映」を待たずに Scene に適用されます。

:::

## 看板を配置する

1. Studio の Lights タブを開き、「入場時の光過敏の警告」の「入場時に表示」をオンにします。看板が Scene に配置されます。
2. 「Scene ビューで表示」を押します。Scene ビューに看板が表示されます。
3. 看板の位置と向きを設定します。
4. 「同意するまで通行できない範囲」の幅と高さを設定します。

![看板の位置と通行できない範囲](/img/studio/lights-notice.png)

## 言語と文を変更する

1. 「言語」で、看板の言語を選択します。「コンソールと同じ」を選択できます。
2. 必要に応じて、見出し・本文・ボタンの文を変更します。

![看板の文](/img/studio/lights-notice-text.png)
