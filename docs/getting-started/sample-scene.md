# サンプルシーン

公開ワールドの展示室を縮めたシーンです。スピーカーの置き方と、Inspector の設定の手本として使えます。

| サンプルシーン | 入っているファイル |
| --- | --- |
| 照明システムなし | Audiorium の unitypackage（本体） |
| 照明システムあり | AudioriumLightingSystem の unitypackage（照明システム） |

## 開く

サンプルシーンは、[外部依存パッケージ](./requirements.md#外部依存パッケージ) のいくつかを使います。先にプロジェクトに追加し、[インストール](./install.md) の順番で Audiorium をインポートしてから、Project ウィンドウでシーンのファイルを開きます。

## 動画プレイヤーを置く

サンプルシーンには動画プレイヤーが入っていません。展示室の正面の額に合わせて置き、Audiorium につなぎます。

1. 動画プレイヤーのプレハブを Hierarchy へドラッグし、Transform を次の値にします。Rotation はすべて 0 です。

   | 動画プレイヤー | プレハブ | Position | Scale |
   | --- | --- | --- | --- |
   | YamaPlayer | `YamaPlayer.prefab` | X 0、Y 3.135、Z 7.28 | 2.88 |
   | VizVid | `VVMW (On-Screen Controls).prefab` | X 0、Y -0.105、Z 7.28 | 2.16 |

   {/* 未確認：この表の Position と Scale は、showroom-compact が配布用の複製（main d1dce444）で測った値。発売用の書き出しの後のサンプルシーンで、画面が額に合うことを確かめ直したら、この印を消す。印が残っている間は公開しない */}

2. Hierarchy で `AudioriumSetup` を選択し、Inspector の「動画プレイヤー」の欄へ、Hierarchy から動画プレイヤーをドラッグします。スピーカーとコンソールは置き直されず、そのままつながります。

## 含まれていない物

公開ワールドにある次の物は、サンプルシーンには含まれていません。

- 入口の通路からアトリウムまでの空間
- QvPen
- 入退室ボード
- エリア切り替えの表示
- 各種効果音（コンソールの効果音を除く）

## 改変して使う場合

改変したシーンは、**File › Save As** で `Assets/Audiorium` の外へ別の名前で保存します。新しいバージョンの Audiorium をインポートすると、サンプルシーンは上書きされます。
