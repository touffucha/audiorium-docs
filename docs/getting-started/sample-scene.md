# サンプルシーン

公開ワールドの展示室を縮めたシーンです。スピーカーの置き方と、Inspector の設定の手本として使えます。設計図の通路から始まり、入場時の光過敏の警告を通って展示室に着きます。

| サンプルシーン | 入っているファイル |
| --- | --- |
| 照明なし | `Audiorium_1.0.0.unitypackage`（本体） |
| 照明あり | `AudioriumLightingSystem_1.0.0.unitypackage`（照明システム） |

## 開く

サンプルシーンは、[別途入手するパッケージ](./requirements.md#別途入手するパッケージ) のいくつかを使います。先にプロジェクトに追加し、[インストール](./install.md) の順番で Audiorium をインポートしてから、Project ウィンドウでシーンのファイルを開きます。

:::info YamaPlayer を入れる前に開いた場合

Hierarchy と Inspector に「Missing」と表示されます。YamaPlayer をプロジェクトに追加すると、すべての参照がつながり、表示が消えます。サンプルシーンの不具合ではありません。

{/* 画像を戻す場所：![YamaPlayer を入れる前に開いたサンプルシーン。Missing と表示される](/img/sample/missing.png)。配布物ができてから撮る */}

:::

## 含まれていない物

公開ワールドにある次の物は、サンプルシーンには含まれていません。

- アトリウムと入口の通路
- ペン
- 入退室を記録するボード
- 字幕
- 現在位置の表示
- 音（コンソールの効果音を除く）と、部屋の残響

## 改変して使う場合

改変したシーンは、**File › Save As** で `Assets/Audiorium` の外へ別の名前で保存します。新しいバージョンの Audiorium をインポートすると、サンプルシーンは上書きされます。
