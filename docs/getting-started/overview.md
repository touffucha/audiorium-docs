# できること

Audiorium は、VRChat のワールドに配置する音響・演出コンソールです。動画プレイヤーの音をワールドのスピーカーから鳴らし、ユーザーがワールド内のコンソールで音の響き、照明、視界エフェクトを操作します。

購入前に、[公開ワールド](https://vrchat.com/home/launch?worldId=wrld_3b124d05-d1c4-4ae3-a216-0b58c5f82ab9)で操作を試せます。

## 2 つの画面

| 画面 | 使う人 | 説明 |
| --- | --- | --- |
| Audiorium Studio | ワールド制作者 | Unity でセットアップに使うエディター拡張。[セットアップ](../guides/speaker-position.md)の各ページで使います |
| コンソール | ユーザー | ワールド内の操作盤。[ユーザーの操作](../console/operation.md)で説明します |

## できること

| できること | 詳細 |
| --- | --- |
| 動画の音を、Stereo・Surround・Surround + Top のスピーカーから鳴らす | [クイックスタート](./quick-start.md) |
| 音の響きをプリセットで切り替える | [Sound Mode のプリセットを編集する](../guides/edit-presets.md) |
| スピーカーごとに EQ、Reverb、音量を調整する | [ユーザーの操作](../console/operation.md) |
| ムービングライトの色と動きを操作する（照明システムが必要） | [照明を配置する](../guides/lights.md) |
| 音に連動する視界エフェクトを切り替える（AudioLink が必要） | [AudioLink と連携する](../integrations/audiolink.md) |
| コンソールを操作できる人を限定する | [操作権限を設定する](../console/permissions.md) |
