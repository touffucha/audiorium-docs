# できること

Audiorium は、VRChat のワールドに設置する音響・演出コンソールです。動画プレイヤーの音をワールドに配置したスピーカーから鳴らし、音の響き、照明、視界エフェクトをワールド内のコンソールで操作します。

ご購入前に、[公開ワールド](https://vrchat.com/home/launch?worldId=wrld_3b124d05-d1c4-4ae3-a216-0b58c5f82ab9)で操作をお試しいただけます。公開ワールドの展示用の演出（照明、空間の装飾）とシーンは、商品に含まれません。

## 構成

| 名前 | 役割 | 使う人 |
| --- | --- | --- |
| Audiorium Studio | セットアップに使うエディター拡張。メニューの **Tools › Audiorium › Studio** から開きます | ワールド制作者 |
| コンソール | ワールドに配置する操作盤。来訪者が音響と演出を操作します | 来訪者 |
| スピーカー | 動画プレイヤーの音を鳴らす音源。Studio がレイアウトに合わせて配置します。スピーカーの 3D モデルは含まれません | — |
| 照明システム | ムービングライト、ストロボ、LED バーのセット。拡張パッケージ（別売）です | — |

## ワールド制作者ができること

- 動画プレイヤーを選択するだけで、スピーカーとコンソールを配置できます。
- スピーカーのレイアウトを Stereo、Surround、Surround + Top から選択し、Scene ビューで位置を調整できます。
- レイアウトを反映すると、視聴位置で適正レベルになるように各スピーカーの音量が揃えられます。音量のバランスは図で確認できます。
- 音の響きのプリセットの名前・説明文・値を変更し、入室時に適用するデフォルトプリセットを選択できます。
- コンソールの設置モデル（床、壁、卓上、手元、空中）とカラーテーマ（16 種類）を選択できます。
- ワールド全体の設定の操作権限を、全員、インスタンスオーナー、登録したユーザーから選択できます。
- 照明システムのセットを、図で位置と向きを決めて配置できます（拡張パッケージが必要です）。

Studio は日本語、英語、中国語、韓国語で表示できます。

## 来訪者ができること

コンソールには 4 つのタブがあります。

| タブ | 内容 | 反映される範囲 |
| --- | --- | --- |
| Sound Mode | 音の響きのプリセットの切り替え。調整した音を 3 つまで保存できます | ワールド全体 |
| Speaker EQ | スピーカーごとの EQ、Reverb、音量の調整 | ワールド全体 |
| Live | 照明の色、パターン、速さ、キュー（照明システムが必要です） | ワールド全体 |
| Effects | 音に連動する視界エフェクトと、LTCGI の点灯と強さ | 操作した人の画面のみ |

ワールド全体に反映される操作は、ワールド制作者が選択した操作権限を持つ人だけが行えます。Effects は操作権限の対象外です。

![コンソールの Sound Mode タブ](/img/home/console-sound.webp)

## 対応していないこと

- Quest（Android）には対応していません。PC 版の VRChat のワールドで使用します。
- 対応する動画プレイヤーは YamaPlayer と VizVid です。Audiorium に接続できる動画プレイヤーは 1 台です。
