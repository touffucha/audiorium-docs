# Audiorium を更新する

新しいバージョンの unitypackage を上書きしてインポートします。変更点は [更新履歴](../changelog.md) で確認できます。

## 更新する

1. プロジェクトのバックアップを取り、作業中の Scene を保存します。
2. 新しいバージョンの `Audiorium_x.y.z.unitypackage` を Unity のウィンドウへドラッグします。
3. 「Import Unity Package」のウィンドウで、すべての項目にチェックが入っていることを確認し、「Import」を押します。
4. 照明システム（拡張パッケージ）を使用している場合は、同じ手順で照明システムの新しいバージョンをインポートします。

## 更新が反映されない場合

上書きしてインポートしても動作が変わらない場合は、次の順に実行します。

1. Project ウィンドウで `Assets/Audiorium` を右クリックし、「Reimport」（日本語の表示では「再インポート」）を押します。
2. それでも変わらない場合は、バックアップがあることを確認してから `Assets/Audiorium` を削除し、unitypackage をインポートし直します。

名前が変わったファイルは、上書きしてインポートすると古い名前のまま残ることがあります。手順 2 で削除してからインポートすると、古いファイルは残りません。
