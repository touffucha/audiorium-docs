# LTCGI

LTCGI は、スクリーンの映像の光をワールドの物体に映す仕組みです。Audiorium での扱いは「任意」です。

| 項目 | 内容 |
| --- | --- |
| 動作確認済みの版 | 1.7.4 |
| 入手先 | [ltcgi.dev](https://ltcgi.dev/) |

## LTCGI で使える機能

Scene に LTCGI を配置すると、コンソールの Effects タブで LTCGI のオン・オフと強さを操作できます。操作は、操作した人の画面にのみ反映されます。

Studio の [Effects](../studio/effects.md) タブの「この Scene との連携」で、LTCGI が Scene にあるかを確認できます。

## 導入する

1. LTCGI をプロジェクトに導入し、LTCGI の手順に従って Scene に配置します。
2. Studio の Effects タブで、LTCGI の行に「未配置」が表示されていないことを確認します。

LTCGI の配置と設定の方法は、LTCGI の配布ページをご確認ください。

:::warning クレジットの表示

LTCGI を使用するワールドには、LTCGI の規約に基づきクレジットの表示が必要です。

:::
