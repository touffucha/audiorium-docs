# 入場時の光過敏の警告

ワールドに入ったユーザーに、光の点滅への注意を表示します。ユーザーが同意のボタンを押すまで、先へ進めないようにします。照明を置くと、最初からオンで置かれます。

照明の Inspector（外部設定の「照明を選択」）の、「入場時の光過敏の警告」の節で設定します。

![入場時の光過敏の警告の節](/img/lights/notice.png)

| 項目 | 内容 |
| --- | --- |
| 入場時に表示 | オンで警告を置きます。オフにすると警告を削除します |
| 警告を選択 | 警告を Hierarchy で選択します |
| 言語 | ワールドで表示する警告の言語。「来訪者の言語に合わせる」・日本語・English |
| 見出し | 警告の見出し |
| 本文 | 警告の本文 |
| ボタン | 同意するときに押すボタンの文字 |

## 言語

| 選択肢 | 表示される言語 |
| --- | --- |
| 来訪者の言語に合わせる | VRChat の言語が日本語のユーザーには日本語、それ以外のユーザーには English |
| 日本語 | すべてのユーザーに日本語 |
| English | すべてのユーザーに English |

「来訪者の言語に合わせる」のときは、Inspector の表示言語の文を編集します。日本語の文を編集するときは、Inspector の Language を日本語にします。

警告のフォントに無い文字を入力すると、「次の文字はコンソールのフォントに含まれていません」と表示されます。その文字は、ワールドで表示されません。

## 位置と通行止めの範囲

1. 「警告を選択」を押します。
2. Scene ビューで、警告の位置と、同意するまで通れない範囲を合わせます。

警告は、ワールドの入り口から照明のある場所までの通り道に置きます。

![Scene ビューの警告。通行止めの範囲が表示されている](/img/scene/notice.png)
