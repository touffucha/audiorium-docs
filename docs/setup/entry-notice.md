# 入場時の光過敏の警告

ワールドに入ったユーザーに、光の点滅への注意を表示します。ユーザーが同意のボタンを押すまで、先へ進めません。照明システムを配置すると、警告も配置されます。

照明システムの Inspector（外部設定の「照明システムを選択」）の「入場時の光過敏の警告」の節で設定します。

![入場時の光過敏の警告の節](/img/lights/notice.png)

| 項目 | 内容 |
| --- | --- |
| 入場時に表示 | オンで警告を配置します。オフにすると警告を削除します。デフォルトはオンです |
| 言語 | ワールドで表示する警告の言語（下の表） |
| 見出し・本文・ボタン | 警告の文言。ボタンは同意するときに押すボタンの文字です |

## 言語

| 選択肢 | 表示される言語 |
| --- | --- |
| 来訪者の言語に合わせる | VRChat の言語が日本語のユーザーには日本語、それ以外のユーザーには English |
| 日本語 | すべてのユーザーに日本語 |
| English | すべてのユーザーに English |

- 「来訪者の言語に合わせる」のときは、Inspector の表示言語の文を編集します。日本語の文は、Inspector の Language を日本語にして編集します。
- 「次の文字はコンソールのフォントに含まれていません」と表示された文字は、ワールドで表示されません。

## 位置と通行止めの範囲

「警告を選択」を押し、Scene ビューで警告の位置と、同意するまで通れない範囲を調整します。

警告は、ワールドの入り口から照明のある場所までの通り道に配置します。
