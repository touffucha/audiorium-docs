# 照明システム

照明システム（拡張パッケージ）で、ムービングライトなどの照明を置きます。ユーザーはコンソールの Live タブで操作します。照明システムは、本体の後にインポートします（[インストール](../getting-started/install.md)）。

## 照明を置く

次のどちらかで置きます。

- `AudioriumSetup` の Inspector の [外部設定](./external.md) で、「照明」をオンにする

  ![外部設定の「照明」](/img/lights/external-lights.png)

- `AudioriumSetup` を選択し、**Tools › Audiorium › Add Lights**（Hierarchy の右クリックの **Audiorium Lights** でも同じ）

`AudioriumSetup` の中に `AudioriumLights` が追加され、ムービング（吊り）・ライトショー・光過敏の警告が置かれます。警告の設定は [入場時の光過敏の警告](./entry-notice.md) を参照してください。

![照明を置いた後の Hierarchy。AudioriumLights の中にムービング（吊り）・ライトショー・光過敏の警告](/img/lights/hierarchy.png)

照明を削除するときは、外部設定の「照明」をオフにします。Ctrl+Z で元に戻せます。

## 照明の Inspector

外部設定の「照明を選択」で開きます。

![照明を置いた直後の照明の Inspector](/img/lights/inspector.png)

| 項目 | 内容 |
| --- | --- |
| 一覧 | 置いている照明と支え。同じ種類が複数あるときは番号が付きます |
| ムービングライト | 置いているムービングライトの台数と上限（16 台） |
| ライトショー | コンソールの Live タブから操作する照明の制御。照明を置くと自動で接続されます |

## 照明を追加する

一覧の下の「+」で種類を選択します。照明はスクリーンの前に追加されます。

| 種類 | 内容 |
| --- | --- |
| ムービング（吊り） | 天井や梁、トラスに取り付けます。ライトショーに合わせてビームが動きます |
| ムービング（床置き） | 床やスタンドに置いて上方を照らします。天井の低い部屋に向いています |
| ストロボ | 一瞬だけ強く発光します。コンソールの Strobe で発光します |
| LED バー | 細長い LED の照明で、広い範囲を色で染めます。コンソールの Wash と曲に合わせて発光します |
| トラス | 照明を吊る金属の枠。支柱は無いため、天井の近くに置きます |
| スタンド | 床に自立する高さ 2.2 m の三脚。脚の開きは約 1.8 m。上の横棒にムービング（床置き）を載せます |

ムービングライトは、吊りと床置きを合わせて **16 台まで**置けます。16 台を置いているときは、メニューのムービング（吊り）とムービング（床置き）が選択できなくなります。

![全種類を 1 台ずつ追加した状態](/img/lights/inspector-many.png)

## 照明の位置を調整する

一覧の行をダブルクリックすると照明が選択されます。Scene ビューで移動と回転を行います。

位置の基準は、台座（取り付ける面）です。台座を天井・トラス・床・スタンドに合わせて置きます。

![Scene ビューの照明。トラス、スタンド、ムービングライトなど](/img/scene/lights.png)

## トラスの長さを変える

長さは 0.5〜20 m です。

- **Scene ビュー**：両端の緑のつまみを引きます。0.5 m 刻みで変わり、反対側の端は動きません。
- **Inspector の「長さ (m)」**：中心から両側へ伸び縮みします。

![トラスの両端のつまみ](/img/scene/truss-handles.png)

![トラスの Inspector の「長さ (m)」](/img/lights/truss-inspector.png)

## ユーザーの操作

照明の色・動き・キューは、コンソールの Live タブで操作します（[コンソールの操作](../console/operation.md#live)）。操作できる人は [詳細](./advanced.md#操作権限) の操作権限で決まります。
