# 照明システム

照明システム（拡張パッケージ）で、ムービングライトなどの照明を配置します。ご利用いただくには、フルセットもしくは、拡張パッケージのご購入が必要です。ユーザーはコンソールの Live タブで操作します。照明システムは、本体の後にインポートします（[インストール](../getting-started/install.md)）。

## 照明システムを配置する

次のどちらかで配置します。

- `AudioriumSetup` の Inspector の [外部設定](./external.md) で、「照明システム」をオンにする

  ![外部設定の「照明システム」](/img/lights/external-lights.png)

- `AudioriumSetup` を選択し、**Tools › Audiorium › Add Lights**（Hierarchy の右クリックメニューの **Audiorium › Add Lights** でも同じ）

`AudioriumSetup` の中に `AudioriumLights` が追加され、ムービング（吊り）・ライトショー・光過敏の警告が配置されます。警告の設定は [入場時の光過敏の警告](./entry-notice.md) を参照してください。

![照明システムを配置した後の Hierarchy。AudioriumLights の中にムービング（吊り）・ライトショー・光過敏の警告](/img/lights/hierarchy.png)

外部設定の「照明システム」をオフにすると、照明システムは無効になり、ビルドに含まれなくなります。配置と設定は残り、オンに戻すと元どおりになります。

## 照明システムの Inspector

外部設定の「照明システムを選択」で開きます。

![照明システムを配置した直後の照明システムの Inspector](/img/lights/inspector.png)

| 項目 | 内容 |
| --- | --- |
| 一覧 | 配置している照明と支え。同じ種類が複数あるときは番号が付きます |
| ムービングライト | 配置しているムービングライトの台数と上限（16 台） |
| ライトショー | コンソールの Live タブから操作する照明の制御。照明を配置すると自動で接続されます |

## 照明を追加する

一覧の下の「+」で種類を選択します。照明はスクリーンの前に追加されます。

| 種類 | 内容 |
| --- | --- |
| ムービング（吊り） | 天井や梁、トラスに取り付けます。音に反応してビームが動きます。 |
| ムービング（床置き） | 床やスタンドに設置して上方を照らします。 |
| ストロボ | 高速で明滅します。コンソールの Strobe で発光します。光の明滅に敏感な方への配慮が必要です。 |
| LED バー | 細長い LED の照明で、広い範囲を色で染めます。コンソールの Wash と曲に合わせて発光します |
| トラス | 照明を吊る金属の枠。 |
| スタンド | ムービング（床置き）が載った三脚です。 |

ムービングライトは、吊りと床置きを合わせて **16 台まで**配置できます。上限の 16 台を配置しているときは、メニューのムービング（吊り）とムービング（床置き）が選択できなくなります。

![全種類を 1 台ずつ追加した状態](/img/lights/inspector-many.png)

## 照明の位置を調整する

一覧の行をダブルクリックすると照明が選択されます。Scene ビューで移動と回転を行います。

![Scene ビューの照明。トラス、スタンド、ムービングライトなど](/img/scene/lights.png)

## トラスの長さを変更する

長さは 0.5〜20 m です。

- **Scene ビュー**：両端の緑のつまみを引きます。0.5 m 刻みで変わり、反対側の端は動きません。
- **Inspector の「長さ (m)」**：中心から両側へ伸び縮みします。

![トラスの両端のつまみ](/img/scene/truss-handles.png)

![トラスの Inspector の「長さ (m)」](/img/lights/truss-inspector.png)

## ユーザーの操作

ライトショーを接続すると、コンソールに Live タブが表示され、照明の色・動き・キューを操作できます（[コンソールの操作](../console/operation.md#live)）。操作できるユーザーは [詳細](./advanced.md#操作権限) の操作権限で決まります。
