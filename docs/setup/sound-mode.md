# Sound Mode

コンソールの Sound Mode タブに並ぶ、音の響きのプリセットを設定します。プリセットは 5 つです（Cinema・Concert・Lounge・Submerged・Radio）。

![Sound Mode の節。Cinema を選択した状態](/img/setup/sound-mode.png)

## デフォルトプリセット

ユーザーがワールドに入ったときに使われるプリセットです。

## プリセットを編集する

一覧でプリセットを押し、その下の項目を変更します。

- 変更はすぐに Scene に反映されます。スライダーは、動かし終えると反映されます。
- 変更したプリセットは、名前の後に「*」が付きます。

### 名前と説明

「プリセット名」はコンソールのプリセットのカードに、「説明 1 行目」「説明 2 行目」はカードの名前の下に表示されます。次のケースでは、ダイアログが表示され、変更前の名前と説明に戻ります。

| ケース | ダイアログの文 |
| --- | --- |
| 名前が空、またはほかのプリセットと同じ名前 | プリセットには、重複しない名前を設定してください。 |
| コンソールのフォントに無い文字（一部の漢字など）を含む | 次の文字はコンソールのフォントに含まれていません：（文字） |
| 名前がコンソールのカードに収まらない | 名前がコンソールのカードに収まりません。短くしてください。 |
| 説明の行がカードに収まらない | 説明文の行がコンソールのカードに収まりません。短くするか、改行してください。 |

### Volume・EQ・Reverb

| 項目 | 内容 |
| --- | --- |
| Level | このプリセットの音量。0 dB で元の音量のままです |
| Low Cut | この周波数より低い音をカットします |
| High Cut | この周波数より高い音をカットします |
| Low Cut Q・High Cut Q | それぞれの周波数付近の強調の度合い。1.0 では強調しません |
| Type | 残響の種類。Room（短い）・Hall（中くらい）・Cathedral（長い）・Off（残響なし） |
| Wet | 残響音の音量。0 % で残響がなくなります |
| Reverb Send | 音を Reverb へ送る量。大きいほど残響が増えます |
| Reverb Level | 原音に対する残響の量。上げると全体の音量も上がります |
| Decay | 残響が消えるまでの時間 |
| HF Decay | 高域の残響が消えるまでの時間。短くすると残響が暗くなります |
| Pre-Delay | 残響が始まるまでの時間 |

## 初期値に戻す

変更したプリセットは、節の一番下の「（プリセット名）の初期値に戻す」を押し、確認のダイアログで「リセット」を押すと、名前・説明を含めて初期値に戻ります。Ctrl+Z で元に戻せます。

![Cinema を変更した後。一覧の「Cinema *」と、下の「Cinema の初期値に戻す」](/img/setup/sound-mode-edited.png)

## ユーザーが操作できること

ユーザーはコンソールでプリセットを切り替え、スピーカーごとの EQ・Reverb・音量を調整できます。ユーザーの操作は Scene のプリセットを変更しません（[コンソールの操作](../console/operation.md)）。
