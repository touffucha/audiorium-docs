# Sound Mode

コンソールの Sound Mode タブに並ぶ、音の響きのプリセットを設定します。プリセットは 5 つです（Cinema・Concert・Lounge・Submerged・Radio）。この節は、最初は閉じています。

![Sound Mode の節。Cinema を選択した状態](/img/setup/sound-mode.png)

## デフォルトプリセット

ユーザーがワールドに入ったときに使われるプリセットを選択します。

## プリセットを編集する

1. プリセットの一覧から、編集するプリセットを押します。一覧の右には、Low Cut の周波数と Reverb の種類が表示されます。
2. 一覧の下の項目を変更します。

変更はすぐに Scene に反映されます。スライダーは、動かし終えると反映されます。元に戻すときは Ctrl+Z を押します。

変更したプリセットは、一覧の名前の後に「*」が付きます。

### 名前と説明

| 項目 | 内容 |
| --- | --- |
| プリセット名 | コンソールのプリセットのカードに表示される名前 |
| 説明 1 行目・説明 2 行目 | カードの名前の下に表示される説明 |

名前や説明がコンソールのカードに収まらない場合は、ダイアログが表示され、変更は反映されません。短くするか、説明を 2 行に分けます。

### Volume

| 項目 | 内容 |
| --- | --- |
| Level | このプリセットの音量。0 dB で元の音量のままです。スライダーの縦線が 0 dB の位置です |

### EQ

グラフに、カットする帯域が表示されます。

| 項目 | 内容 |
| --- | --- |
| Low Cut | この周波数より低い音をカットします |
| Low Cut Q | Low Cut の周波数付近の強調の度合い。1.0 では強調しません |
| High Cut | この周波数より高い音をカットします |
| High Cut Q | High Cut の周波数付近の強調の度合い。1.0 では強調しません |

### Reverb

| 項目 | 内容 |
| --- | --- |
| Type | 残響の種類。Room（短い）・Hall（中くらい）・Cathedral（長い）・Off（残響なし） |
| Wet | 残響音の音量。0 % で残響がなくなります |
| Reverb Send | 音を Reverb へ送る量。大きいほど残響が増えます |
| Reverb Level | 原音に対する残響の量。上げると全体の音量も上がります |
| Decay | 残響が消えるまでの時間 |
| HF Decay | 高域の残響が消えるまでの時間。短くすると残響が暗くなります |
| Pre-Delay | 残響が始まるまでの時間 |

## 初期値に戻す

変更したプリセットには、節の一番下に「（プリセット名）の初期値に戻す」が表示されます。押すと確認のダイアログが表示され、「リセット」を押すと、名前・説明を含めて初期値に戻ります。Ctrl+Z で取り消せます。

![Cinema を変更した後。一覧の「Cinema *」と、下の「Cinema の初期値に戻す」](/img/setup/sound-mode-edited.png)

## ユーザーが操作できること

ユーザーは、コンソールでプリセットを切り替え、スピーカーごとの EQ・Reverb・音量を調整できます。ユーザーの操作は Scene のプリセットを変えません。詳しくは [コンソールの操作](../console/operation.md) を参照してください。
