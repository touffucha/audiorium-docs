# スピーカー

置くスピーカーを一覧で選択し、位置を Scene ビューで調整します。

![スピーカーの節。Add Audiorium の直後](/img/setup/speakers.png)

## スピーカーの種類

![真上から見たスピーカーの配置。Add Audiorium の直後](/img/setup/speaker-layout.svg)

| スピーカー | 出力数 | 鳴らす位置 |
| --- | --- | --- |
| Front | 2 | 画面の左右。外せません |
| Surround | 2 | 視聴位置の横と後ろ |
| Top Middle | 2 | 視聴位置の真上 |
| Stereo Mix | 1 | スクリーンの中心。動画の音をステレオのまま鳴らします |
| Subwoofer | 1 | スクリーンの中心。動画の音の低音を鳴らします |

出力は、合わせて **8 つまで**使えます。置いた直後は 8 つすべてを使っています。

## 追加と削除

- **外す**：一覧のチェックを外します。チェックを入れ直すと、初期の位置に置き直されます。
- **追加する**：一覧の下の「+」を押します。スピーカーは動画プレイヤーの位置に追加されます。
- **追加したスピーカーを削除する**：行を選択して「−」を押します。

出力を 8 つ使っている間は追加できません。先に、使わないスピーカーのチェックを外します。

## 位置を調整する

一覧の行をダブルクリックするとスピーカーが選択されます。Scene ビューで移動と回転を行います。

「ギズモを表示」をオンにすると、各スピーカーの音が届く範囲が Scene ビューに表示されます。

![Scene ビューのスピーカーと視聴位置。音が届く範囲が表示されている](/img/scene/speakers.png)

### 視聴位置

視聴位置（`AudioriumSetup` の中の `ListeningPosition`）は、スピーカーの音が届く範囲を決める基準の位置です。Add Audiorium が、画面の正面に自動で置きます。通常は、動かす必要はありません。客席がこの位置から数 m 以上離れているときだけ、Scene ビューで動かします。

Hierarchy で `ListeningPosition` か `AudioriumSetup` を選ぶと、Scene ビューに視聴位置が表示されます。動かすと、スピーカーの音が届く範囲の円がその場で変わります。金色の円は、視聴位置で大きさが決まる円です。

### 動画プレイヤーを移動した場合

スピーカー・コンソール・視聴位置は、動画プレイヤーを移動しても動きません。Hierarchy で `AudioriumSetup` を選択して同じだけ移動すると、中にあるスピーカー・コンソール・視聴位置が一緒に動きます。

## スピーカーごとの設定

Hierarchy でスピーカーを選択すると、Inspector に設定が表示されます。

![スピーカー（Front）を選択したときの Inspector](/img/setup/speaker-inspector.png)

| 項目 | 内容 |
| --- | --- |
| 入力 | つなぐ動画プレイヤーの音源。音源が 1 つの場合は変更できません |
| 役割 | Add Audiorium が配置したスピーカーは名前で、追加したスピーカーは視聴位置から見た位置で決まります |
| 出力ごとの補正 | ワールドの音響に合わせた音量の補正。コンソールやプリセットの操作では変更されません |
| 音が届く範囲を設定 | 「2D で聴こえる範囲」の内側は 2D で聴こえます。外側は 3D へ移行しながら音量が下がり、「音が消える距離」で無音になります |
