# スピーカー

置くスピーカーを選択し、スピーカーを追加します。スピーカーの位置は Scene ビューで調整します。

![スピーカーの節。Add Audiorium の直後](/img/setup/speakers.png)

## スピーカーの種類

![真上から見たスピーカーの配置。Add Audiorium の直後](/img/setup/speaker-layout.svg)

| スピーカー | 出力数 | 鳴らす位置 |
| --- | --- | --- |
| Front | 2 | 画面の左右。常に置かれ、外せません |
| Surround | 2 | 視聴位置の横と後ろ |
| Top Middle | 2 | 視聴位置の真上 |
| Stereo Mix | 1 | 動画プレイヤーの位置。動画の音をステレオのまま鳴らします |
| Subwoofer | 1 | 動画プレイヤーの位置。動画の音の低音を鳴らします |

置いた直後は、すべてのスピーカーが置かれています。出力は合わせて 8 つまで使えます。

## スピーカーを外す・置き直す

一覧のチェックを外すと、そのスピーカーが削除されます。削除したスピーカーの欄には「未使用」と表示されます。もう一度チェックを入れると、初期の位置に置き直されます。

## スピーカーを追加する

1. 一覧の下の「+」を押します。
2. 「L / R ペア」か「単体スピーカー」を選択します。

![単体スピーカーを追加し、その行を選択した状態](/img/setup/speakers-custom.png)

スピーカーは動画プレイヤーの位置に追加されます。Scene ビューで位置を調整します。

出力が 8 つ使われている場合は追加できません。使わないスピーカーのチェックを外してから追加します。

追加したスピーカーを削除するときは、一覧でその行を選択し、「−」を押します。「−」で削除できるのは、追加したスピーカーだけです。

## スピーカーを移動する

1. 一覧のスピーカーの欄を押すと、Hierarchy でそのスピーカーが示されます。ダブルクリックすると選択されます。
2. Scene ビューで移動と回転を行います。

「ギズモを表示」をオンにすると、Scene ビューに各スピーカーの音が届く範囲が表示されます。

![Scene ビューのスピーカーと視聴位置。音が届く範囲が表示されている](/img/scene/speakers.png)

## 視聴位置を移動する

視聴位置は、ユーザーが動画を視聴する位置です。スピーカーの音量のバランスの基準になります。Hierarchy の `AudioriumSetup` の中にある `ListeningPosition` を選択し、Scene ビューで客席の中央に移動します。

## 動画プレイヤーを移動した場合

Audiorium を置いた後に動画プレイヤーを移動すると、Scene ビューの `AudioriumSetup` の位置に「画面に合わせる」のボタンが表示されます。

![動画プレイヤーを移動した後に表示される「画面に合わせる」](/img/scene/follow-player.png)

押すと、スピーカー・コンソール・視聴位置が、動画プレイヤーとの位置の関係を保ったまま移動します。床からの高さはそのまま残ります。

## スピーカーごとの設定

Hierarchy でスピーカーを選択すると、Inspector にそのスピーカーの設定が表示されます。

![スピーカー（Front）を選択したときの Inspector](/img/setup/speaker-inspector.png)

| 項目 | 内容 |
| --- | --- |
| 入力 | 動画プレイヤーのどの音源をつなぐか。動画プレイヤーの音源が 1 つの場合は変更できません |
| 種類 | L / R ペア、単体 · Stereo、単体 · L、単体 · R |
| 役割 | Front・Surround・Ceiling など。視聴位置から見たスピーカーの位置で自動的に決まります |
| 出力ごとの補正 | ワールドの音響に合わせた、出力ごとの音量の補正。コンソールやプリセットの操作では変更されません |
| 音が届く範囲を設定 | 「2D で聴こえる範囲 (m)」と「音が消える距離 (m)」を入力し、「この範囲を適用」を押します。内側は 2D、外側へ進むと 3D へ移行しながら音量が下がり、指定した距離で無音になります |

「Audiorium Setup に戻る」を押すと、`AudioriumSetup` が選択されます。
