# 詳細

コンソールの動きと、音声の処理を設定します。この節は、最初は閉じています。

![詳細の節](/img/setup/advanced.png)

## コンソール

| 項目 | 内容 |
| --- | --- |
| デフォルト画面 | コンソールで最初に表示するタブ。Sound Mode・Speaker EQ・Effects・Live のうち、コンソールにあるタブから選択します。Scene のコンソールの表示も切り替わります |
| 操作権限 | コンソールの Sound Mode・Speaker EQ・Live のタブを操作できる人 |

### 操作権限

Sound Mode・Speaker EQ・Live の操作は、ワールド全体に反映されます。これらのタブを操作できる人を選択します。

| 選択肢 | 操作できる人 |
| --- | --- |
| 全員 | インスタンスにいる全員。最初はこれが選択されています |
| インスタンスオーナー | インスタンスオーナーのみ |
| 登録したユーザー | 一覧に表示名を登録したユーザーのみ |

「登録したユーザー」を選択すると、表示名の一覧が表示されます。「+」で行を追加し、VRChat の表示名を入力します。大文字と小文字を区別するため、表示名を正確に入力してください。

![操作権限を「登録したユーザー」にし、表示名を 2 件登録した状態](/img/setup/advanced-named.png)

Effects は操作権限の対象外です。各ユーザーが自分の画面について個別に切り替えます。

操作権限の無い人のコンソールでは、GLOBAL の下に「権限がありません」と表示され、Sound Mode・Speaker EQ・Live の操作部品が暗く表示されます。操作しても反映されず、「操作権限なし」の操作音が鳴ります。

![操作権限の無い人に表示されるコンソールの Sound Mode タブ](/img/console/sound-locked.webp)

## UI 操作音

コンソールを操作したときに鳴る音です。

| 項目 | 内容 |
| --- | --- |
| Volume | 操作音の大きさ |
| 押下・オン | ボタンを押したとき、スイッチをオンにしたとき |
| オフ | スイッチをオフにしたとき |
| スライダー操作 | スライダーを動かしているとき |
| スライダー解放 | スライダーを離したとき |
| 操作権限なし | 操作権限の無い人が操作したとき |

音を変えるときは、Project ウィンドウから音声ファイル（AudioClip）を欄へドラッグします。

## 音声

| 項目 | 内容 |
| --- | --- |
| 音声バッファ | 再生の前にためる音声の長さ。長いほど途切れにくく、映像より遅れます |

| 選択肢 | 内容 |
| --- | --- |
| 安定 | 遅延は大きくなりますが、音が途切れにくくなります |
| 標準 | 遅延と途切れにくさのバランスを取ります。最初はこれが選択されています |
| 低遅延 | 音が映像に近くなりますが、途切れやすくなります |

選択肢の横に、おおよその遅延（ms）が表示されます。
