# 視界エフェクト

コンソールの Effects タブと、そこに表示する画面酔いの注意を設定します。この節は、最初は閉じています。

![視界エフェクトの節](/img/setup/visual-effects.png)

| 項目 | 内容 |
| --- | --- |
| Effects を有効化 | コンソールに Effects タブを置き、視界エフェクトを使えるようにします。最初はオンです |
| 画面酔いの注意 › 表示 | Effects タブに画面酔いの注意文を表示します。最初はオンです |
| 画面酔いの注意 › 注意文 | Effects タブに表示する文。Inspector の表示言語が日本語のときは日本語の文を、それ以外のときは英語の文を編集します |

## Effects タブが表示される条件

コンソールに Effects タブが表示されるのは、次の両方を満たす場合です。

- 「Effects を有効化」がオン
- [外部設定](./external.md) で AudioLink か LTCGI がオン

視界エフェクトの種類と、ユーザーの操作は [コンソールの操作](../console/operation.md#effects) で説明します。視界エフェクトは、操作した人の画面にのみ反映されます。
