# 視界エフェクト

コンソールの Effects タブと、そこに表示する画面酔いの注意を設定します。

![視界エフェクトの節](/img/setup/visual-effects.png)

| 項目 | 内容 |
| --- | --- |
| Effects を有効化 | コンソールに Effects タブを置きます。デフォルトはオンです |
| デフォルト › Effects を有効にする | オンにすると、ワールドに入った人の Effects タブが、下の BEAT・LOOK・WORLD で選んだ効果がオンの状態で始まります。オフのときは、入った時点ではどの効果もオフで、各自が Effects タブで付けます。デフォルトはオフです |
| デフォルト › BEAT・LOOK・WORLD | 入った時点でオンにする効果と、選んでおく LOOK です。「Effects を有効にする」がオンのときだけ選べます |
| デフォルト › LTCGI を有効にする | 入った時点で LTCGI の画面の光をオンにします。「Effects を有効にする」とは別に決められます。デフォルトはオンです |
| 画面酔いの注意 › 表示 | Effects タブに画面酔いの注意文を表示します。デフォルトはオンです |
| 画面酔いの注意 › 注意文 | Inspector の表示言語が日本語のときは日本語の文を、それ以外のときは英語の文を編集します |

デフォルトの行は、Effects タブを操作したことのない人にだけ効きます。一度操作した人には、その人が保存した設定が使われます。「Effects を有効にする」から WORLD までの行は AudioLink が、LTCGI の行は LTCGI がワールドにある場合に表示されます。

欄の下に「次の文字はコンソールのフォントに含まれていません」と出た文字は、コンソールで表示されません。

## Effects タブが表示される条件

次の両方を満たすと表示されます。

- 「Effects を有効化」がオン
- [外部設定](./external.md) で AudioLink か LTCGI がオン

視界エフェクトは、操作した人の画面にのみ反映されます。種類と操作は [コンソールの操作](../console/operation.md#effects) を参照してください。
