# Audiorium コンソール

ワールドに配置するコンソールのカラーテーマとモデルを選択します。選択した組み合わせは、Inspector 内のプレビューで確認することができます。

![Audiorium コンソールの節。テーマは Graphite、モデルは枠のみ](/img/setup/console.png)

| 項目 | 内容 |
| --- | --- |
| テーマ | コンソールの配色。見本にマウスを重ねると、テーマの説明が表示されます |
| モデル | コンソールを載せる台 |
| マテリアル | 台の色と質感。ホワイトかチャコール。モデルが「枠のみ」「なし」のときは選択できません |
| ドック装着音 | モデルが「置き台」のときだけ表示されます。手持ちのコンソールを置き台に戻したときに鳴る音です |

デフォルトは、テーマが Graphite、モデルが枠のみです。マテリアルは台のあるモデルで選択でき、デフォルトはホワイトです。

## モデル

![モデルの一覧](/img/setup/console-models.png)

| モデル | 内容 |
| --- | --- |
| 枠のみ | 台を配置せず、画面に枠を付けます |
| 床置き | 床に立てるスタンド |
| 卓上 | 机やカウンターに設置する台 |
| 壁掛け | 壁に掛ける台 |
| 手持ち | 手に持って操作するコンソール |
| 置き台 | 手持ちのコンソールと、それを戻す置き台 |
| なし | 画面だけを配置します |

![モデルが置き台のとき](/img/setup/console-cradle.png)

## テーマ

テーマは 16 種類です。

![テーマの一覧](/img/setup/console-themes.png)

## コンソールの位置を変更する

「コンソールを選択」を押すと、コンソールが Hierarchy で選択されます。台のあるモデルでは、台ごと選択されます。Scene ビューで移動と回転を行います。AudioSource の配置には影響しません。
