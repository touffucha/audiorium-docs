# Audiorium コンソール

ワールドに置くコンソールの配色と台を選択します。節の下の見本に、選択した組み合わせが表示されます。

![Audiorium コンソールの節。テーマは Graphite、モデルは床置き](/img/setup/console.png)

| 項目 | 内容 |
| --- | --- |
| テーマ | コンソールの配色。見本にマウスを重ねると、テーマの説明が表示されます |
| モデル | コンソールを載せる台 |
| マテリアル | 台の色と質感。ホワイトかチャコール。モデルが「枠のみ」「なし」のときは選択できません |
| ドック装着音 | モデルが「置き台」のときだけ表示されます。手持ちのコンソールを置き台に戻したときに鳴る音です |
| コンソールを選択 | コンソールと台を Hierarchy で選択します |

最初は、テーマが Graphite、モデルが床置き、マテリアルがホワイトです。

## モデル

![モデルの一覧](/img/setup/console-models.png)

| モデル | 内容 |
| --- | --- |
| 床置き | 床に立てるスタンド |
| 卓上 | 机やカウンターに置く台 |
| 壁掛け | 壁に掛ける台 |
| 手持ち | 手に持って操作するコンソール |
| 置き台 | 手持ちのコンソールと、それを戻す置き台 |
| 枠のみ | 台を置かず、画面に枠を付けます |
| なし | 画面だけを置きます |

「置き台」を選択すると、「ドック装着音」の行が表示されます。

![モデルが置き台のとき](/img/setup/console-cradle.png)

## テーマ

![テーマの一覧](/img/setup/console-themes.png)

| テーマ | 配色 |
| --- | --- |
| Graphite | 暖かみのある炭の灰。選んだ物は生成り。コンソールの基本 |
| White | 黄みも青みも無い白に、墨の字。明るい部屋向け |
| Pure Black | 真っ黒の地に白。暗い部屋でいちばん締まる |
| Smoke | 色なしで、斜めに炭から灰へ |
| Slate | 青みの灰に、灰に近い鋼色 |
| Mist | 霧のような薄い青灰に、濃紺 |
| Navy | 落ち着いた紺に、淡い氷色 |
| Twilight | 縦に、夜の紺から薄紫へ明るむ |
| Deep Sea | 深い青緑に、淡い水色 |
| Aurora | 斜めに、青緑から藍へ |
| Forest | 深い緑に、淡い若草 |
| Aubergine | 茄子紺に、淡い藤色 |
| Bordeaux | 深いワインに、くすんだ薔薇色 |
| Umber | 焦げ茶に、真鍮 |
| Ember | 横に 3 色、焦げ茶から琥珀へ |
| Pigeon | 鳩が並ぶ生成りの地に、茶の緑 |

## コンソールの位置を変更する

1. 「コンソールを選択」を押します。コンソールと台が Hierarchy で選択されます。
2. Scene ビューで移動と回転を行います。

スピーカーは動きません。
