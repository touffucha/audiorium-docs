# Audiorium

Audiorium は、VRChat のワールドに設置する音響・演出コンソールです。このリポジトリには、購入された方向けのドキュメントサイトの原稿を置いています。

- ドキュメント: https://touffucha.github.io/audiorium-docs/
- [インストール手順](install.md)
- [更新履歴](changelog.md)

お問い合わせは、BOOTH ショップのメッセージよりお願いいたします。

## サイトの更新

`docs/` の Markdown と `src/` を編集し、`main` に push すると、GitHub Actions が GitHub Pages へ公開します。手元で確認するときは `npm ci` の後に `npm start` を実行します。
